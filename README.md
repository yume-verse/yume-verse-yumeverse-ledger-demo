# 夢次元記帳 網頁測試版

Yumeverse 夢次元記帳 iOS App（`new-ui` 版）的**網頁測試版**，畫面與操作跟 App 一樣，用來讓其他人遠端測試。

- 手機、平板、電腦瀏覽器都能用；窄螢幕是底部分頁，寬螢幕是左側欄
- 單一檔案 `index.html`，不需要安裝，也可以離線開啟
- 資料只存在打開的那個瀏覽器分頁，重新整理就會還原，不會寫入 Notion 或營運總表
- App 原始碼不在這個 repo

## 測試帳號

| 身分 | 帳號 | 密碼 |
|---|---|---|
| 公司管理員 | `company` | `yume2026` |
| Coser・ここあ | `cocoa` | `demo2026` |
| Coser・小桃（測試） | `momo` | `demo2026` |

登入頁也可以直接點測試帳號登入。

## 測試資料

登入前可以選：

- **Notion 現況**：服裝 42 件與借用 3 筆照 Notion 2026-10-20 的資料
- **完整測試情境**：依當天日期產生逾期、今天到期、暫停借用、未來預約，方便測每個畫面

想從頭再試：「更多」→「重設測試資料」。

## 可以試的流程

- **公司管理員**：首頁（依日期看收入、各 Coser 收入、待處理）→ 收銀對帳（錢箱、待收款項登記已收）→ 服裝狀態 → 預約紀錄（服裝借用、場地預約，只看）。記帳由各 Coser 負責，公司沒有快速結帳
- **Coser**：記帳（選日期 → 依作品・角色選商品 → 收款）→ 我的商品（新增、進貨、停售、改顏色）→ 預約（預約服裝 3 步驟、預約攝影棚／工作室，工作室有 QR code）→ 我的銷售 →「更多」打開會員卡
