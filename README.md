# 夢次元記帳 網頁展示版

Yumeverse 夢次元記帳 iOS App 的**網頁展示版**，用來遠端查看 App 目前的畫面與操作流程。

- 依 iOS App（SwiftUI）的畫面與流程還原，手機、平板、電腦瀏覽器都能操作
- **所有資料皆為示意**（活動、商品、金額、粉絲 ID、服裝清單），只存在你自己的瀏覽器，不會寫入 Notion
- App 原始碼不在這個 repo

## 示意帳號

| 身分 | 帳號 | 密碼 |
|---|---|---|
| 公司管理員 | `company` | `demo` |
| Coser・小桃 | `momo` | `demo` |
| Coser・小凜 | `rin` | `demo` |

登入頁也可以直接點「快速填入示意帳號」。

## 可以試的流程

- **公司管理員**：營運總覽（指標卡、待收款提醒、收款紀錄方式、各個 Coser 目前金額）→ 帳務（只看待收款、登記已收）→ 活動收銀對帳 → 庫存 → 更多（記帳、會員、服裝借用）
- **Coser**：記帳（選主題 → 加入購物車 → 收款）→ 庫存盤點／補貨 → 服裝借用（填借用單、登記歸還）
- 想從頭再試一次：右上角 ⚙︎ →「重設示意資料」

## 說明

- 網頁展示版是另一份程式，用來看畫面與流程；正式 App 的 Notion 同步、離線重送等功能不在這裡。
- 單一檔案 `index.html`，不需要安裝任何東西。
